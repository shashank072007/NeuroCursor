<objective>
Generate the verified 10-frame JSON sample (`mock_frames.json`) and a synthetic frame generator (`vision/mock.py`) to unblock Samrudh (backend queue consumer) and Sampada (frontend cursor UI) immediately, allowing them to build without waiting for live camera testing.
</objective>

<context>
The handoff specification requires:
- A 10-frame JSON sample demonstrating normal centered tracking, deliberate head motion, expression triggers, face occlusion/lost event, and recovery.
- A synthetic frame generator that backend/frontend can run standalone with `--mock` flag.
</context>

<tasks>
1. Define the exact JSON schema matching the contract:
   - `timestamp`: Unix epoch float
   - `frame_index`: int
   - `detected`: bool
   - `face`: `{"quality": float, "width_norm": float}` (or null if detected=false)
   - `pointer`: `{"nx": float, "ny": float}` (or null if detected=false)
   - `raw_motion`: `{"raw_dx": float, "raw_dy": float}` (or null if detected=false)
   - `gesture`: `{"name": str, "score": float, "held_ms": int}` (name="none", score=0.0, held_ms=0 if detected=false)
   - `timing`: `{"capture_ms": float, "process_ms": float, "fps": float}`
2. Write `mock_frames.json` with 10 sequential realistic frames covering:
   - Frames 1-3: Neutral centered face tracking
   - Frames 4-5: Head motion to top-right (`nx=0.72, ny=0.35`, positive `raw_dx`, negative `raw_dy`)
   - Frames 6-7: Gesture activation (`"mouth_open"` with `held_ms=250`)
   - Frame 8: Asymmetric expression (`"wink_left"` with `held_ms=180`)
   - Frame 9: Occlusion / Face lost (`detected=false`, null pointer & raw_motion, gesture `"none"`)
   - Frame 10: Face re-acquisition and recovery (`detected=true`, `quality=0.91`, center coordinates)
3. Implement `vision/mock.py` containing `MockFrameGenerator` that can stream these frames or procedurally generate continuous frames at 30 FPS.
</tasks>

<verification>
Validate `mock_frames.json` against `json.loads` and assert that all 10 frames conform strictly to the null-out rule when `detected=false`.
</verification>
