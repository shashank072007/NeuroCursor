<objective>
Implement MediaPipe Face Mesh landmark extraction (`vision/landmarks.py`) with face quality scoring `face.quality ∈ [0.0, 1.0]`, processing latency tracking (`process_ms`), and the strict null-out contract when face is lost or tracking quality is unacceptable.
</objective>

<context>
MediaPipe Face Mesh provides 468+ 3D landmarks.
The team contract strictly requires:
- `face.quality`: Formula combining landmark presence, face size sanity, and pose tilt sanity.
- Null-out guarantee: If face is not detected or quality < quality_threshold (default 0.5), return `detected=False` with all motion coordinates set to `None` and gestures to `"none"`. Stale coordinates must NEVER be repeated.
- Measure `process_ms` accurately on every frame.
</context>

<tasks>
1. Define key Face Mesh landmark indices:
   - Nose tip: index 1
   - Left eye corners/pupil: indices 33, 133, 159, 145, 468 (if refine_landmarks)
   - Right eye corners/pupil: indices 362, 263, 386, 374, 473
   - Outer lips: 61, 291, 0, 17; Inner lips: 13, 14
   - Left eyebrow: 70, 63, 105, 66, 107; Right eyebrow: 300, 293, 334, 296, 336
   - Chin: 152, Forehead: 10
2. Create `FaceMeshExtractor` wrapping MediaPipe Face Mesh (`refine_landmarks=True`, `max_num_faces=1`, `min_detection_confidence=0.5`, `min_tracking_confidence=0.5`).
3. Implement `compute_face_quality(landmarks, frame_w, frame_h)`:
   - Size Score: `width_ratio = face_width / frame_w`. Ideal is ~0.35. Penalize if <0.12 (too far) or >0.80 (too close).
   - Pose Sanity: Check eye tilt angle and nose position relative to eye midpoint.
   - Visibility / Confidence score.
   - Final weighted score in [0.0, 1.0].
4. Implement `process_frame(frame)`:
   - Convert BGR to RGB.
   - Measure `process_ms` via `perf_counter()`.
   - If face detected and quality >= threshold: return structured `FaceMeshResult(detected=True, landmarks=..., quality=..., width_norm=..., center_x=..., center_y=..., process_ms=...)`.
   - If face lost or quality < threshold: return `FaceMeshResult(detected=False, landmarks=None, quality=0.0, ...)` ensuring no old coordinate repetition.
5. Provide a helper method `draw_debug_landmarks(frame, result)` to draw key landmark points and bounding box on the OpenCV frame.
</tasks>

<verification>
Unit test `FaceMeshExtractor` with:
- An empty/black frame -> verifies `detected=False`, quality=0.0, and graceful return.
- Landmark extraction timings verifying `process_ms` is populated.
</verification>
