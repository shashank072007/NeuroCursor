<objective>
Implement pointer tracking coordinate translation and filter pipeline (`vision/tracking.py`) to map head displacement to smoothed, boundary-clamped normalized coordinates `nx, ny ∈ [0, 1]`, while keeping unsmoothed `raw_dx, raw_dy` (in face-width units) separate for backend jitter and range loss estimation. Never convert to screen pixels.
</objective>

<context>
The team contract specifies:
- "Map movement to normalized nx, ny in [0,1]. Apply smoothing and clamp values."
- "Keep raw_dx/raw_dy separate from smoothed nx/ny because the backend needs raw movement to estimate jitter and range."
- "Do not convert to screen pixels."
- "If face is lost or quality is unacceptable, set detected=false and nx, ny, raw_dx, raw_dy ... to null; never repeat old coordinates."
- "The backend combines your signals with guard rejection and gesture data into an interaction-effort proxy."
</context>

<tasks>
1. Create `OneEuroFilter` (or Adaptive EMA filter) for 2D coordinates:
   - Configurable `min_cutoff` (for jitter suppression when user is steady) and `beta` (for zero-latency responsiveness during intentional swift motion).
   - Reset capability when face tracking is lost to prevent rubber-band snaps upon re-detection.
2. Implement `PointerTracker`:
   - Accepts a `CalibrationProfile` (or uses default).
   - `update(face_result: FaceMeshResult) -> TrackingResult`:
     - If `not face_result.detected`:
       - Reset smoothing filter state.
       - Return `TrackingResult(detected=False, nx=None, ny=None, raw_dx=None, raw_dy=None)`.
     - Compute raw displacements from neutral:
       - `dx_raw = face_result.center_x - profile.neutral_x`
       - `dy_raw = face_result.center_y - profile.neutral_y`
       - Scale by `profile.face_width_ref` to achieve scale-invariance:
         - `raw_dx = dx_raw / profile.face_width_ref`
         - `raw_dy = dy_raw / profile.face_width_ref`
     - Map to normalized cursor `(target_nx, target_ny)`:
       - Horizontal:
         - if `raw_dx >= 0`: `target_nx = 0.5 + 0.5 * (raw_dx / profile.range_right)`
         - if `raw_dx < 0`: `target_nx = 0.5 - 0.5 * (abs(raw_dx) / profile.range_left)`
       - Vertical:
         - if `raw_dy >= 0`: `target_ny = 0.5 + 0.5 * (raw_dy / profile.range_down)`
         - if `raw_dy < 0`: `target_ny = 0.5 - 0.5 * (abs(raw_dy) / profile.range_up)`
     - Clamp `target_nx, target_ny` to `[0.0, 1.0]`.
     - Apply smoothing filter to get `(nx, ny)`.
     - Clamp smoothed `(nx, ny)` to `[0.0, 1.0]`.
     - Return `TrackingResult(detected=True, nx=round(nx, 3), ny=round(ny, 3), raw_dx=round(raw_dx, 4), raw_dy=round(raw_dy, 4))`
3. Verify that coordinates remain strictly normalized in [0, 1] and are never converted to screen pixels.
</tasks>

<verification>
Unit test `PointerTracker` verifying:
- Resting at neutral pose produces `nx ≈ 0.5, ny ≈ 0.5, raw_dx ≈ 0.0, raw_dy ≈ 0.0`.
- Moving right produces `nx > 0.5, raw_dx > 0`.
- Clamping prevents `nx, ny` from escaping [0.0, 1.0].
- When face is lost, `nx, ny, raw_dx, raw_dy` are strictly `None` and filter state resets.
</verification>
