<objective>
Implement the debounced facial expression detection engine (`vision/gestures.py`) strictly conforming to the shared expression enum, suppressing ordinary involuntary blinks, computing calibration-relative scores, and tracking continuous held duration (`held_ms`). Vision must never map expressions to clicks.
</objective>

<context>
The team contract specifies:
- "Emit only none, mouth_open, brow_raise, smile, wink_left, wink_right. Do not emit ordinary blinks."
- "Compute score relative to the user's calibration and continuous held_ms."
- "Add debounce/stability so a one-frame expression does not become a sustained gesture."
- "Each expression emits once per hold and has a stable held_ms progression."
- "Gesture names exactly match shared enum; vision never maps them to clicks."
- "If face is lost or quality is unacceptable, set gesture values to null/none as specified; never repeat old coordinates."
</context>

<tasks>
1. Define strict `GestureEnum`:
   - `NONE = "none"`
   - `MOUTH_OPEN = "mouth_open"`
   - `BROW_RAISE = "brow_raise"`
   - `SMILE = "smile"`
   - `WINK_LEFT = "wink_left"`
   - `WINK_RIGHT = "wink_right"`
2. Define `GestureResult` dataclass:
   - `name: str` (strictly from GestureEnum)
   - `score: float` in [0.0, 1.0] (relative to calibration)
   - `held_ms: int` (continuous duration since activation)
   - `raw_scores: Dict[str, float]`
3. Implement raw score calculation using MediaPipe blendshapes and landmark ratios:
   - `mouth_open`: combines `jawOpen` and calibrated inner mouth ratio.
   - `brow_raise`: combines `browInnerUp` and calibrated brow-to-eye vertical ratio.
   - `smile`: combines `mouthSmileLeft` and `mouthSmileRight`.
   - `wink_left`: left eye closed AND right eye open.
   - `wink_right`: right eye closed AND left eye open.
   - **Blink Filter**: If both eyes blink (`abs(left - right) < 0.20` and both high), treat as ordinary blink -> suppress winks and emit `"none"`.
4. Implement `DebounceStateMachine`:
   - Requires an expression candidate to persist for `activation_threshold_frames` (default: 2-3 frames, ~60-90ms) before transitioning to active.
   - Filters out isolated 1-frame spikes.
   - Tracks `held_ms = int((now - start_time) * 1000)` while the user maintains the gesture.
   - Release debounce: requires `release_threshold_frames` (default: 2 frames) below deactivation threshold before resetting to `"none"`.
5. Implement `update(face_result, timestamp)`:
   - If `not face_result.detected`: reset debounce state, return `GestureResult(name="none", score=0.0, held_ms=0)`.
   - Returns structured `GestureResult` on every frame.
</tasks>

<verification>
Unit test `GestureDetector` verifying:
- Strict adherence to the 6 allowed enum names.
- Bilateral blinks (both eyes closed) emit `name="none"` (never winks).
- Isolated single-frame expression spike does NOT trigger an active gesture (debounce filtering).
- Holding an expression across multiple frames shows monotonically increasing `held_ms`.
- Face loss immediately resets gesture to `name="none", score=0.0, held_ms=0`.
</verification>
