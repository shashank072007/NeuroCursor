<objective>
Implement the interactive debug visualizer (`main_debug.py`) providing a live OpenCV HUD overlay showing detected face, key landmarks, real FPS, tracking quality, tracking viewport crosshair, active expression feedback, and guided calibration controls.
</objective>

<context>
The team contract specifies:
- "Draw a debug view showing detected face, key landmarks, FPS and tracking quality."
- "Handle camera unavailable, face out of frame and poor lighting without crashing."
- Keyboard controls:
  - 'c': Start calibration sequence (neutral -> left -> right -> up -> down).
  - 's': Skip current calibration step.
  - 'r': Retry current calibration step.
  - 'q' / ESC: Quit.
</context>

<tasks>
1. Build `main_debug.py` running the real-time vision loop or mock stream.
2. Render visual HUD elements:
   - Facial contour & landmark anchor dots (eyes, nose, mouth).
   - Top status bar: measured FPS, capture latency (`capture_ms`), processing latency (`process_ms`), lighting warning if active.
   - Quality gauge: colored visual bar for `face.quality ∈ [0.0, 1.0]`.
   - Virtual cursor preview box in top-right corner mapping normalized `(nx, ny)` to a mini screen representation with tracking crosshair.
   - Active gesture banner: displays active expression name in green/gold, score, and `held_ms`.
   - Calibration prompt overlay: displays step instructions ("Look straight ahead", "Move left comfortably") with countdown timer.
3. Support CLI arguments:
   - `--camera <index>`: Select camera device (default 0).
   - `--mock`: Run with synthetic frame generator if no webcam is connected.
   - `--profile <path>`: Load custom calibration JSON.
</tasks>

<verification>
Verify `main_debug.py --mock` runs for at least 30 frames and exits cleanly with 0 errors.
</verification>
