<objective>
Implement the QA test harness and chaos simulator (`simulator.py`) for Shashank to simulate low range, high jitter, and intermittent tracking loss, validating backend effort-proxy and fail-safe recovery without needing physical camera manipulation.
</objective>

<context>
The handoff specification states:
- "Tell Shashank how to simulate low range, jitter and tracking loss for tests."
- The simulator generates synthetic frame streams and allows controllable injection of noise, restricted range, and occlusion drops.
</context>

<tasks>
1. Implement `VisionChaosSimulator`:
   - Configurable chaos parameters:
     - `jitter_sigma`: Standard deviation of Gaussian jitter injected into `raw_dx, raw_dy` (e.g. 0.05 for high tremor).
     - `range_compression`: Multiplier scaling excursion range down (e.g. 0.25 to simulate severe motor limitation).
     - `occlusion_frequency`: Injects `detected=False` bursts every N frames to test tracking loss recovery.
     - `gesture_spikes`: Injects 1-frame expression glitches to test debounce suppression.
2. CLI interface with subcommands:
   - `--mode [jitter|low_range|occlusion|all]`: selects test pattern.
   - `--duration <sec>`: run duration in seconds.
   - `--queue`: pushes into shared Python queue for backend integration testing.
   - `--output <path>`: dumps recorded test frames to JSON.
3. Provide automated assertions verifying that:
   - During occlusion frames, coordinates and gestures are strictly nulled out.
   - Jitter injection creates measurable high variance in `raw_dx, raw_dy` for the backend's effort estimation.
</tasks>

<verification>
Run `python simulator.py --mode all --duration 1` and verify valid output schema.
</verification>
