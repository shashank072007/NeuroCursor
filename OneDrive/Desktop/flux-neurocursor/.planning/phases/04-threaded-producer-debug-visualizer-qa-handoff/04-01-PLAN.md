<objective>
Implement the threaded, non-blocking frame producer (`vision/producer.py`) that captures camera frames, runs landmark extraction, computes tracking coordinates and expressions, constructs the agreed frame event schema, and places it onto a bounded, drop-oldest queue with clean shutdown handling.
</objective>

<context>
The team contract specifies:
- "vision/producer.py — constructs the agreed frame event and puts it on the shared queue."
- "Queue producer never blocks camera loop indefinitely; use bounded queue/drop-oldest strategy if needed."
- "Confirm queue name, frame frequency and shutdown behavior for Samrudh."
</context>

<tasks>
1. Implement `FrameProducer` class:
   - Initializes `CameraManager`, `FaceMeshExtractor`, `PointerTracker`, `GestureDetector`.
   - Accepts or creates a `queue.Queue(maxsize=10)` (bounded to prevent memory growth if consumer is slow).
   - Starts a background daemon capture thread (`_run_loop`).
2. Implement non-blocking drop-oldest enqueue strategy:
   - When queue is full: pop and discard the oldest frame (`get_nowait()`) before pushing the newest frame (`put_nowait()`).
   - Ensures zero latency buildup and keeps consumer aligned with real-time state.
3. Build the standardized frame event payload:
   - `timestamp`: float
   - `frame_index`: int
   - `detected`: bool
   - `face`: `{"quality": float, "width_norm": float}` or `None`
   - `pointer`: `{"nx": float, "ny": float}` or `None`
   - `raw_motion`: `{"raw_dx": float, "raw_dy": float}` or `None`
   - `gesture`: `{"name": str, "score": float, "held_ms": int}`
   - `timing`: `{"capture_ms": float, "process_ms": float, "fps": float}`
4. Implement clean shutdown:
   - `stop()` sets a `threading.Event`, joins thread, and releases camera and model resources cleanly.
   - Context manager `__enter__` and `__exit__`.
</tasks>

<verification>
Unit test `FrameProducer` verifying:
- Background worker starts and enqueues frame events.
- Full queue drops oldest frame without raising `queue.Full` or blocking.
- Clean shutdown stops thread and closes resources.
</verification>
