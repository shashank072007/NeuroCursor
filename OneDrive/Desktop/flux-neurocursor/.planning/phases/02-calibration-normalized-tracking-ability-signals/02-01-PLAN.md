<objective>
Implement the calibration engine (`vision/calibration.py`) to guide users through neutral pose acquisition and comfortable head movement range estimation without forcing extreme movements, supporting skip/retry options and JSON profile persistence.
</objective>

<context>
The team contract specifies:
- "At calibration start, ask the user to sit comfortably and look straight ahead. Collect a short neutral sample and store neutral x/y and face width."
- "Ask for comfortable left/right/up/down movement and estimate usable range. Do not ask the user to force a movement; allow skip/retry."
- Baseline expression ratios must also be sampled during neutral calibration to anchor downstream gesture detection in Phase 3.
- Allow saving and loading from `calibration.json` to prevent repetitive re-calibration during hackathon testing.
</context>

<tasks>
1. Create `CalibrationProfile` dataclass:
   - `neutral_x`, `neutral_y`: center resting coordinates in [0, 1].
   - `face_width_ref`: reference normalized face width.
   - `range_left`, `range_right`: maximum comfortable horizontal excursion in face-width units (default ~0.25).
   - `range_up`, `range_down`: maximum comfortable vertical excursion in face-width units (default ~0.20).
   - `neutral_mouth_ratio`: baseline inner mouth height / width ratio.
   - `neutral_brow_ratio`: baseline brow distance to eye / face height ratio.
   - `neutral_left_ear`, `neutral_right_ear`: baseline eye aspect ratios.
   - Methods: `to_dict()`, `from_dict()`, `save(path)`, `load(path)`.
2. Implement `CalibrationManager`:
   - State machine with states: `IDLE`, `COLLECTING_NEUTRAL`, `RANGE_LEFT`, `RANGE_RIGHT`, `RANGE_UP`, `RANGE_DOWN`, `COMPLETE`.
   - `start_neutral(sample_duration_sec=1.5)`: collects resting pose frames, discards outliers, averages center_x, center_y, face width, and baseline ratios.
   - `record_range_direction(direction, sample_duration_sec=2.0)`: observes user's comfortable excursion in face-width units; calculates 90th percentile peak displacement.
   - `skip_current_step()`: applies conservative safe defaults for the active direction so the user is never forced into discomfort.
   - `retry_step()`: clears current direction buffer and restarts the step.
   - Safe fallback: if not calibrated, provides valid default profile (`neutral_x=0.5, neutral_y=0.5, face_width_ref=0.35, ranges=0.25`).
</tasks>

<verification>
Unit test `CalibrationManager` verifying:
- Neutral collection computes valid averages and stores `face_width_ref`.
- Skip functionality applies valid defaults without error.
- Profile serialization to/from JSON matches exactly.
</verification>
