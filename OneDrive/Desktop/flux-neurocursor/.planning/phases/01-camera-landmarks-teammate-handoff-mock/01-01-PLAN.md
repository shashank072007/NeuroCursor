<objective>
Implement the robust camera capture module (`vision/camera.py`) to open the laptop webcam, measure frame capture latency (`capture_ms`), track actual running FPS, monitor ambient lighting conditions, and handle disconnections or busy devices gracefully without crashing.
</objective>

<context>
The vision pipeline requires a non-crashing camera wrapper that satisfies the hackathon team contract:
- Target >= 25 FPS, reporting real measured FPS (no fake promises).
- Capture time tracking (`capture_ms`) on every acquired frame.
- Automatic reconnection attempt or clear status when camera is unavailable or busy.
- Lighting evaluation (mean luma/brightness) to flag poor lighting before face tracking fails.
</context>

<tasks>
1. Create `CameraManager` in `vision/camera.py` with configurable camera index, resolution (default 640x480 for low-latency MediaPipe processing), and target FPS.
2. Implement camera opening with backend fallback (`cv2.CAP_DSHOW` on Windows, fallback to default `cv2.CAP_ANY`).
3. Implement `read_frame()` returning `(success, frame, capture_ms, metadata)`.
4. Implement sliding-window FPS calculator (e.g. over the last 30 frames).
5. Implement lighting estimation using grayscale mean brightness; set `low_light=True` if brightness < 40.
6. Implement clean `release()` and context manager support (`__enter__`, `__exit__`).
</tasks>

<verification>
Run a standalone check verifying:
- CameraManager initializes and can attempt capture or fail gracefully if no physical camera is attached.
- `capture_ms` and `fps` properties return valid floats.
</verification>
